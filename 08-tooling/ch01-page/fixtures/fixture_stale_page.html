After this chapter you can:

These chapter objectives serve the course outcomes LO-1 and LO-4.

Floating point

Floats are stored in binary, so some decimal fractions cannot be represented exactly: 0.1 + 0.2 evaluates to 0.30000000000000004, and round(0.1 + 0.2, 2) gives 0.3 - the reason behind the chapter's closing section, How Computers Store Data with Binary Numbers (Python Software Foundation, 2026).

>>> 0.1 + 0.2

Precedence

Operator precedence decides the result: 2 + 3 * 6 evaluates to 20, while (2 + 3) * 6 evaluates to 30, because ** binds first, then *, /, // and %, then + and -, and parentheses override the order (Python Software Foundation, 2026).

Predict, then run
>>> 2 + 3 * 6
20

Integer division

Floor division and the modulus operator split a division into its whole part and its remainder: 23 // 7 is 3 and 23 % 7 is 2, while 23 / 7 gives the float 3.2857142857142856 (Sweigart, 2025).

>>> 23 // 7

Concatenation

String concatenation joins two strings with +, so 'Alice' + 'Bob' gives 'AliceBob'; joining a string to a number raises a TypeError, because Python does not convert types silently (Sweigart, 2025).

Glossary

IntegerA whole number. Python integers have unlimited precision, so 2 ** 100 is exact.
Floating pointA number with a fractional part, stored in binary, so some decimal values cannot be represented exactly.
StringA sequence of characters written between quotes.
PrecedenceThe order in which operators apply: ** first, then *, /, //, %, then + and -; parentheses override it.
Integer divisionFloor division gives the whole-number quotient; the modulus operator gives the remainder.
ConcatenationJoining two strings with +. Joining a string to a number raises a TypeError.
ReplicationRepeating a string an integer number of times with *.
AssignmentStoring a value in a variable with =; the variable names the value, and the name follows PEP 8's lower_case convention.
