# SEN0414 — Advanced Programming with Python (Fall 2026)

Course materials for **SEN0414 Advanced Programming (2+2 · 3 credits)**, Computer Engineering
Department, İstanbul Kültür University.

**Instructor:** Yusuf Altunel — <y.altunel@iku.edu.tr>
**Lecture:** Friday 14:00–17:45, 2B PC Lab 12/14

---

## Term theme — semantic technologies

Projects this term are expected to serve a **real business or educational need**, not a
hypothetical one. Before proposing, talk to actual users, run the domain engineering properly,
and collect the business requirements. Team projects with clearly divided responsibilities are
preferred over individual ones.
