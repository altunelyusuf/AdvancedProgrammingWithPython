# SEN0414 — Advanced Programming (Fall 2026)

Course repository for **SEN0414 Advanced Programming (2+2 · 3 credits)**, Computer Engineering
Department, İstanbul Kültür University. Python is the language, chosen for its libraries and reach.

## How this repository is organised

It follows **course profile 1** of CME, the Course Management Ecosystem: every part below is governed
by a recognised standard, and each is described ontologically in the part's own folder.

| Folder | Part | Governed by |
|---|---|---|
| `00-course-profile/` | what the course is; the outline | Schema.org Course |
| `01-outcomes/` | eight learning outcomes, each with its source | 1EdTech CASE |
| `02-textbook/` | the textbook, and a pinned reference to its ontology | IEEE LOM |
| `03-materials/` | lecture slides, each described | IEEE LOM |

**No student data is ever held here.** This repository is readable by students.

## Textbook

*Automate the Boring Stuff with Python*, 3rd edition — Al Sweigart, No Starch Press, 2025, free to
read at <https://automatetheboringstuff.com/3e/>. The 3rd edition does not teach multithreading;
that topic draws on the 2nd edition's chapter 17.

## Term theme — semantic technologies

Projects this term serve a **real business or educational need**, not a hypothetical one. Talk to
actual users, run the domain engineering, and collect the requirements before proposing. Team
projects with clearly divided responsibilities are preferred.
